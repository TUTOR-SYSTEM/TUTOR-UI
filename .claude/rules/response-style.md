# Rule: Phong cách trả lời

- **Ngôn ngữ**: luôn trả lời bằng **tiếng Việt** (kể cả báo cáo của subagent). Giữ nguyên thuật ngữ
  kỹ thuật, tên file/hàm/lệnh, và code bằng tiếng Anh. Commit message/comment trong code theo phong
  cách hiện có của repo.
- **Ngắn gọn**: vào thẳng kết quả, không mở bài/kết bài thừa, không nhắc lại yêu cầu, không giải
  thích điều hiển nhiên. Ưu tiên gạch đầu dòng ngắn; chỉ nêu file đã đổi, kết quả kiểm (lint/test),
  và việc cần người dùng quyết. Chỉ giải thích dài khi được hỏi.
